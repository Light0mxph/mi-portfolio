01 / Proyecto insignia

El motor detrás del ecosistema Aztrix.

Una librería para crear plugins de Minecraft más seguros, rápidos y fáciles de mantener. Se ocupa de la infraestructura técnica para que cada proyecto pueda centrarse en la experiencia del jugador.

  • 01
    Trabajo seguro

    Organiza las tareas del servidor para evitar bloqueos y errores difíciles de detectar.

  • 02
    Configuración sencilla

    Centraliza mensajes, permisos y ajustes para administrar cada plugin con claridad.

  • 03
    Compatible de verdad

    Funciona con Paper, Folia, Purpur y Spigot en versiones actuales de Minecraft.

  • 04
    Menos dependencias

    Cada plugin conserva su propio núcleo, sin añadir piezas externas innecesarias.
